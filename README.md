# aweis89/tap

Homebrew tap for [pcode](https://github.com/aweis89/pcode).

```sh
brew install aweis89/tap/pcode          # the pcode CLI
brew install --cask aweis89/tap/pcode   # Pcode.app (Apple Silicon) plus the CLI
```

`Formula/pcode.rb` is updated by pcode's release workflow, and `Casks/pcode.rb`
by the `pcode-app` workflow in
[aweis89/ghostty-smooth](https://github.com/aweis89/ghostty-smooth), on every
tagged release. Edit either here in a pull request, not in those repos.
